## What is SQL?---------

Definition
SQL (Structured Query Language) is a standard programming language used to communicate with relational databases. It helps us store, retrieve, update, and delete data from a database.
SQL is a language that allows us to interact with a database.

Create databases and tables
Insert data
Retrieve data
Update records
Delete records
Analyze data

## What are SQL Commands?-------
Definition------

SQL Commands are instructions used to perform different operations on a database, such as creating tables, inserting data, updating records, deleting data, and controlling transactions.
SQL commands are the instructions we give to the database to perform a task.

## Real-Life Example-----

Imagine a school database.

Create a new student table → CREATE
Add a student → INSERT
Update marks → UPDATE
Delete a student → DELETE
View all students → SELECT

All these are SQL commands.

─────────────────────────────────────────
## Types of SQL Commands-----

####SQL commands are divided into 5 categories:------

Category	Full Form	               Purpose
DDL	       Data Definition Language	       Create and modify database objects
DML	       Data Manipulation Language      Insert, update, delete records
DQL	       Data Query Language	       Retrieve data
DCL	       Data Control Language	       Control user permissions
TCL	       Transaction Control Language    Manage transactions

──────────────────────────────────────────────────────────────────────────────

## 1. DDL (Data Definition Language)------
## Definition----

DDL commands are used to create, modify, and delete database objects like databases and tables.
DDL changes the structure of the database.

## Commands in DDL------

ALTER

The DROP command permanently deletes a database object.

## Definition---------

TRUNCATE removes all records from a table but keeps the table structure.

## Example------

DROP	                              TRUNCATE

## 4. DCL (Data Control Language)----
## Definition------

DCL commands control user access and permissions in a database.

Commands
GRANT
REVOKE

─────────────────────────────────────────────────

## GRANT Command------

Used to give permissions to users.

## Example-----
GRANT SELECT ON Students TO Rahul;

This allows the user Rahul to read data from the Students table.


─────────────────────────────────────────────────

## REVOKE Command-----

Used to remove permissions.

## Example-----
REVOKE SELECT ON Students FROM Rahul;

Now Rahul can no longer read the Students table.

─────────────────────────────────────────────────

## 5. TCL (Transaction Control Language)-------
## What is a Transaction?-------

A transaction is a group of SQL operations treated as a single unit of work.

## Real-Life Example--------

Suppose you transfer ₹5,000 from one bank account to another.

## Steps:------
Deduct ₹5,000 from Account A.
Add ₹5,000 to Account B.

If the second step fails, the first step should also be cancelled. This ensures data remains correct.

─────────────────────────────────────────────────

## TCL Commands------
COMMIT
ROLLBACK
SAVEPOINT

─────────────────────────────────────────────────

## COMMIT-------
## Definition-------

COMMIT permanently saves all changes made during a transaction.

## Example-----
UPDATE Accounts
SET Balance = Balance - 5000
WHERE Account_ID = 101;

COMMIT;

Now the changes are permanently stored.

─────────────────────────────────────────────────

## ROLLBACK----
## Definition-----

ROLLBACK undoes changes made after the last COMMIT.

## Example----
UPDATE Students
SET Course = 'MCA';

ROLLBACK;

The update is cancelled.

─────────────────────────────────────────────────

## SAVEPOINT------
## Definition----

SAVEPOINT creates a checkpoint inside a transaction.

## Example-----
## SAVEPOINT Step1;

If something goes wrong later, you can roll back to this point instead of undoing the entire transaction.

─────────────────────────────────────────────────

## Difference: COMMIT vs ROLLBACK-------

COMMIT	                                  ROLLBACK
Saves changes permanently	          Cancels uncommitted changes
Cannot be undone	                  Restores previous state
Used after successful transaction	  Used when an error occurs

What are Keys in SQL?
Definition

A Key is a column or combination of columns used to identify records uniquely or establish relationships between tables.

Easy Definition

SQL me Key ek special column/columns hoti hain jo records ko identify karne ya tables ko connect karne me help karti hain.

2. Why are Keys Important?

Keys ka use hota hai:

Records ko uniquely identify karne ke liye
Duplicate data ko control karne ke liye
Tables ke beech relationship banane ke liye
Data integrity maintain karne ke liye
3. Types of SQL Keys

Important keys:

Super Key
Candidate Key
Primary Key
Alternate Key
Foreign Key
Composite Key
4. Super Key
Definition

A Super Key is any column or combination of columns that can uniquely identify a record.

Example

Consider:
Student_ID	Email	Name
101	riya@gmail.com	Riya
102	rahul@gmail.com	Rahul

Possible Super Keys:

Student_ID
Email
Student_ID + Name
Email + Name
Student_ID + Email

Agar combination record ko uniquely identify kar raha hai, wo Super Key ho sakta hai.

Easy Way

Super Key = Anything that can uniquely identify a row.

5. Candidate Key
Definition

A Candidate Key is a minimal Super Key that can uniquely identify each record.

"Minimal" ka meaning hai ki usme unnecessary column nahi hona chahiye.

Example:

Student_ID	Email	Name
101	riya@gmail.com	Riya
102	rahul@gmail.com	Rahul

Possible Candidate Keys:
7. Alternate Key
Definition

Candidate keys jo Primary Key ke roop me select nahi ki gayi hain, unhe Alternate Keys kaha jata hai.

Example

Suppose:

Student_ID → Candidate Key
Email      → Candidate Key

Agar hum choose karein:

Student_ID → Primary Key

to:

Email → Alternate Key
8. Foreign Key
Definition

A Foreign Key is a column that references a key, usually a Primary Key, in another table.

Example
Department Table
Dept_ID	Department
1	IT
2	HR
3	Finance

Dept_ID → Primary Key

Employee Table
Employee_ID	Name	Dept_ID
101	Riya	1
102	Rahul	2
103	Amit	1

Employee table ka Dept_ID → Foreign Key

SQL Example
CREATE TABLE Department (
    Dept_ID INT PRIMARY KEY,
    Department_Name VARCHAR(50)
);
CREATE TABLE Employee (
    Employee_ID INT PRIMARY KEY,
    Name VARCHAR(50),
    Dept_ID INT,
    
    FOREIGN KEY (Dept_ID)
    REFERENCES Department(Dept_ID)
);

Relationship:

Department
    │
    │ Dept_ID
    ↓
Employee
Student_ID
Email

Lekin:

Student_ID + Name

candidate key nahi hai, kyunki Student_ID akela hi unique identification ke liye sufficient hai.

6. Primary Key
Definition

A Primary Key is the candidate key selected to uniquely identify records in a table.

Example:

CREATE TABLE Students (
    Student_ID INT PRIMARY KEY,
    Name VARCHAR(50),
    Email VARCHAR(100) UNIQUE
);

Yahan:

Student_ID → Primary Key
Email → Candidate/alternate unique identifier
Properties

Primary Key:

Unique hoti hai
NULL nahi ho sakti
Usually one primary key constraint hota hai per table
Single column ya multiple columns se ban sakti hai

9. Composite Key ⭐
Definition

A Composite Key is a key made up of two or more columns that together uniquely identify a record.

Example

Suppose ek student multiple courses le sakta hai.

Student_ID	Course_ID	Enrollment_Date
101	501	2026-07-01
101	502	2026-07-02
102	501	2026-07-03

Yahan:

Student_ID

alone unique nahi hai.

Aur:

Course_ID

alone bhi unique nahi hai.

Lekin:

Student_ID + Course_ID

together unique hai.

SQL
CREATE TABLE Enrollment (
    Student_ID INT,
    Course_ID INT,
    Enrollment_Date DATE,
PRIMARY KEY (Student_ID, Course_ID)
);

Yahan Student_ID + Course_ID = Composite Primary Key.
