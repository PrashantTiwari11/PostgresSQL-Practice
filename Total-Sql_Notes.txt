## What is SQL?---------

Definition
SQL (Structured Query Language) is a standard programming language used to communicate with relational databases. It helps us store, retrieve, update, and delete data from a database.
SQL is a language that allows us to interact with a database.


─────────────────────────────────────────
## Using SQL, we can:-------

Create databases and tables
Insert data
Retrieve data
Update records
Delete records
Analyze data

## Real-Life Example

## Imagine a school stores information about students.-------

Student ID	  Name	Course	  Marks
101	        Riya	  BCA  	   85
102	        Tushar   B.Tech 	90
103	        Anjali 	BCA	   78
─────────────────────────────────────────────────────────────────
# If the principal wants to:--------

Find students who scored more than 80 marks
Add a new student
Update a student's marks
Delete a student's record

## All these tasks can be done using SQL-----
## Why Do We Use SQL?-----

SQL is used because it makes managing large amounts of data easy.


## Uses of SQL-------

Update information

Generate reports
Analyze business data
Features of SQL

## What are SQL Commands?-------
Definition------

SQL Commands are instructions used to perform different operations on a database, such as creating tables, inserting data, updating records, deleting data, and controlling transactions.
SQL commands are the instructions we give to the database to perform a task.

## Real-Life Example-----

Imagine a school database.

Create a new student table → CREATE
Add a student → INSERT
Update marks → UPDATE
Delete a student → DELETE
View all students → SELECT

All these are SQL commands.

─────────────────────────────────────────
## Types of SQL Commands-----

####SQL commands are divided into 5 categories:------

Category	Full Form	               Purpose
DDL	       Data Definition Language	       Create and modify database objects
DML	       Data Manipulation Language      Insert, update, delete records
DQL	       Data Query Language	       Retrieve data
DCL	       Data Control Language	       Control user permissions
TCL	       Transaction Control Language    Manage transactions

──────────────────────────────────────────────────────────────────────────────

## 1. DDL (Data Definition Language)------
## Definition----

DDL commands are used to create, modify, and delete database objects like databases and tables.
DDL changes the structure of the database.

─────────────────────────────────────────
## Commands in DDL------
CREATE
ALTER
DROP
TRUNCATE
RENAME (supported by many databases)
CREATE Command
Definition

The CREATE command is used to create a new database or a new table.

─────────────────────────────────────────────────
## Syntax-----
(Create Database)
CREATE DATABASE CollegeDB;

## Syntax------ 
(Create Table)
CREATE TABLE Students (
    Student_ID INT,
    Name VARCHAR(50),
    Age INT,
    Course VARCHAR(30)
);

## Output------

A new table named Students is created.

## Real-Life Example

Suppose a new college starts.------

The first step is to create a table to store student records.


─────────────────────────────────────────────────
## ALTER Command------
## Definition-----

The ALTER command is used to modify the structure of an existing table.

## Common Uses----

Add a column
Remove a column
Rename a column
Change a data type

## Example 1: Add a Column------

ALTER TABLE Students
ADD Email VARCHAR(100);

## Result----
Student_ID	Name	Age	Course	Email

## Example 2: Change Data Type-----


─────────────────────────────────────────────────
## DROP Command--------
## Definition------

The DROP command permanently deletes a database object.

## Example------

DROP TABLE Students;

## Result-------
Table deleted
All records deleted
Structure deleted
Cannot be recovered (unless backup exists)

## Real-Life Example------

A company closes permanently and its database is removed.


─────────────────────────────────────────────────

## TRUNCATE Command------
## Definition---------

TRUNCATE removes all records from a table but keeps the table structure.

## Example------
TRUNCATE TABLE Students;

## Result----
Before	         After
Table exists	Table still exists
Data present	All rows removed

## Real-Life Example------

A school starts a new academic session and clears old student records while keeping the same table.

─────────────────────────────────────────────────

## Difference: (DROP vs TRUNCATE)----------

DROP	                              TRUNCATE
Deletes table + data	             Deletes only data
Structure removed	             Structure remains
Table no longer exists	             Table can still be used
Used when table is not needed	     Used when only records need to be removed

─────────────────────────────────────────────────

## 2. DML (Data Manipulation Language)---------
## Definition--------

DML commands are used to insert, update, and delete data from tables.

─────────────────────────────────────────────────
## Commands--------

INSERT
UPDATE
DELETE

─────────────────────────────────────────────────
## INSERT Command--------
## Definition-------

INSERT is used to add new records into a table.

## Syntax-----

INSERT INTO Students
(Student_ID, Name, Age, Course)
VALUES
(101, 'Riya', 21, 'BCA');

## Result-----
Student_ID	Name	Age	Course
101	        Riya	21	BCA


─────────────────────────────────────────────────

## UPDATE Command------
## Definition-------

UPDATE modifies existing records.

## Example-------

UPDATE Students
SET Course = 'MCA'
WHERE Student_ID = 101;

## Before------

Student_ID	Course
101	         BCA

## After-------

Student_ID	Course
101	         MCA

─────────────────────────────────────────────────

## DELETE Command----
## Definition-----

DELETE removes specific records from a table.

## Example-----
DELETE FROM Students
WHERE Student_ID = 101;
Result

Only the student with ID 101 is deleted.

## Important Note------

⚠️ Without WHERE, every row in the table will be deleted.

─────────────────────────────────────────────────

## 3. DQL (Data Query Language)----=--
## Definition-------

DQL is used to retrieve data from the database.

Main Command
SELECT
SELECT Command

## Definition------
SELECT retrieves data from one or more tables.

## Example------
SELECT * FROM Students;

## Result--------

Displays all columns and all rows.
Select Specific Columns
SELECT Name, Course
FROM Students;

─────────────────────────────────────────────────
## 4. DCL (Data Control Language)----
## Definition------

DCL commands control user access and permissions in a database.

Commands
GRANT
REVOKE

─────────────────────────────────────────────────

## GRANT Command------

Used to give permissions to users.

## Example-----
GRANT SELECT ON Students TO Rahul;

This allows the user Rahul to read data from the Students table.


─────────────────────────────────────────────────

## REVOKE Command-----

Used to remove permissions.

## Example-----
REVOKE SELECT ON Students FROM Rahul;

Now Rahul can no longer read the Students table.

─────────────────────────────────────────────────

## 5. TCL (Transaction Control Language)-------
## What is a Transaction?-------

A transaction is a group of SQL operations treated as a single unit of work.

## Real-Life Example--------

Suppose you transfer ₹5,000 from one bank account to another.

## Steps:------
Deduct ₹5,000 from Account A.
Add ₹5,000 to Account B.

If the second step fails, the first step should also be cancelled. This ensures data remains correct.

─────────────────────────────────────────────────

## TCL Commands------
COMMIT
ROLLBACK
SAVEPOINT

─────────────────────────────────────────────────

## COMMIT-------
## Definition-------

COMMIT permanently saves all changes made during a transaction.

## Example-----
UPDATE Accounts
SET Balance = Balance - 5000
WHERE Account_ID = 101;

COMMIT;

Now the changes are permanently stored.

─────────────────────────────────────────────────

## ROLLBACK----
## Definition-----

ROLLBACK undoes changes made after the last COMMIT.

## Example----
UPDATE Students
SET Course = 'MCA';

ROLLBACK;

The update is cancelled.

─────────────────────────────────────────────────

## SAVEPOINT------
## Definition----

SAVEPOINT creates a checkpoint inside a transaction.

## Example-----
## SAVEPOINT Step1;

If something goes wrong later, you can roll back to this point instead of undoing the entire transaction.

─────────────────────────────────────────────────

## Difference: COMMIT vs ROLLBACK-------

COMMIT	                                  ROLLBACK
Saves changes permanently	          Cancels uncommitted changes
Cannot be undone	                  Restores previous state
Used after successful transaction	  Used when an error occurs

1. What is a Data Type?
Definition

A data type defines what kind of value a column can store in a database.

Easy Definition

Data type database ko batata hai ki kisi column me kis type ka data store hoga.

Example
CREATE TABLE Students (
    Student_ID INT,
    Name VARCHAR(50),
    Age INT,
    Marks DECIMAL(5,2),
    Admission_Date DATE
);

Yahan:

Student_ID → number
Name → text
Age → whole number
Marks → decimal number
Admission_Date → date
2. Why are Data Types Important?

Data types important hain because they:

Data ko properly store karte hain
Invalid values ko prevent karte hain
Storage ko efficient banate hain
Calculations ko easy banate hain
Data accuracy maintain karte hain
Example

Agar Age ke liye INT use kiya hai:

Age INT

to normally age me:

21
25
30

store hoga.

Age ko text ke form me store karna unnecessary aur problematic ho sakta hai.

6. FLOAT
Definition

FLOAT approximate decimal numbers store karta hai.

Example:

Values:

36.5

Important

FLOAT approximate values ke liye useful hai.

Exact monetary calculations ke liye generally DECIMAL/NUMERIC prefer kiya jata hai.

7. DECIMAL vs FLOAT
DECIMAL	FLOAT
Exact/precise decimal representation	Approximate representation
Financial calculations ke liye better	Scientific/approximate calculations ke liye useful
Precision important ho to use karein	Large-range approximate numbers ke liye useful
Interview Question

Q. Why is DECIMAL preferred over FLOAT for money?

Answer:
Because DECIMAL is designed for exact decimal representation, while FLOAT uses approximate representation and can introduce small rounding differences.
