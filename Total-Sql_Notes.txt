## What is SQL?---------

Definition
SQL (Structured Query Language) is a standard programming language used to communicate with relational databases. It helps us store, retrieve, update, and delete data from a database.
SQL is a language that allows us to interact with a database.


─────────────────────────────────────────
## Using SQL, we can:-------

Create databases and tables
Insert data
Retrieve data
Update records
Delete records
Analyze data

## Real-Life Example

## Imagine a school stores information about students.-------

Student ID	  Name	Course	  Marks

102	        Tushar   B.Tech 	90
103	        Anjali 	BCA	   78

1. What is Data?

## Definition
Data is a collection of raw facts, figures, or information that can be stored and processed.
Data means any information that we want to save.


## Real-Life Example
Suppose a college stores student details.

101	      Riya	  21	 BCA
102         Tushar  22	 B.Tech
