TOPIC : JOINS IN SQL 
HERE MENTIONED JOIN TYPES DESCRIPTION 
1. INNER JOIN : RETURN ONLY MATCHING ROWS IN BOTH TABLES
2. LEFT JOIN : RETURN ALL ROWS FROM THE LEFT TABLE EVEN IF THERE IS NO MATCH IN THE RIGHT TABLE.
3. RIGHT JOIN : RETURNS ALL THE ROWS FROM THE RIGHT TABLE EVEN IF THERE IS NO MATCH IN THE LEFT TABLE
4. FULL JOIN : RETURN ALL ROWS FROM THE BOTH TABLES , FILLS NULL FOR MISSING MATCHES .
5. CROSS JOIN : RETURN CARTESIAN PRODUCT (EVERY COMBINATION) 

INNER JOIN SYNTAX : 
SELECT COLUMNS FROM TABLE 1 JOIN TABLE 2 
ON TABLE1.COMMON_COOLUMN = TABLE2.COMMON_COLUMN;
